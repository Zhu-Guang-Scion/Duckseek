## §3 联调副产品：embedding 跨语言实验

中文口语问句 → 英文字段名，6 例中 4 例命中。两例失误反而印证三通道（向量 + BM25 +
术语直通）设计：①字面重叠误导语义（字面对得上的英文词并非语义目标）；②生僻词
borough 对中文问句无字面抓手——"行政区"最终靠词典术语直通补位。结论：跨语言
召回不能依赖单一 embedding 通道，混合检索缺一不可。

## §4 V5-D：冻结基线可比性复核（裁定 A，2026-09-20）

**背景**：M4 冻结基线（L1=1.000 / L2=0.95 / L3=0.75）生成于 thinking 默认开启的
旧生成条件；V5-C 已置 `llm.thinking: disabled`。按「指标可对比」原则复跑一轮
e2e 复核（不加 `--save-baseline`）。

**三层对照**：

| 层 | 冻结基线 | 本次复核（thinking=disabled） | 判定 |
|---|---|---|---|
| L1 Recall@3 | 1.000 | 1.000 | 一致 |
| L2 pass | 0.95 | 0.95 | 值同（构成不同，见下） |
| L3 pass（可判/总数） | 0.75 | 0.80 / 0.80 | +1 case（来源 #7，非 #19） |

**逐 case diff（三处变化）**：#7 JFK 街招/网约占比 L3 fail→pass（+1 实际来源，
M4 归档多列形状风格类）；#11 早高峰车费对比 L2/L3 转 error（护栏拒绝 green 表
误用 tpep 时间列——任务书预告的 #11「时间列归因」摆动，护栏按设计拦截）；#16
机场电召费 L2 fail→pass（与 #11 反向抵消，L2 净值不变）。不变项：#19 仍 fail；
#10/#14/#19 冻结风格类失败原样维持；**零退化**（无任何 previously-pass case
退化为 fail）。

**裁定（选项 A）**：冻结基线维持 0.75 不动（禁止 `--save-baseline` 重定——0.75
锚点与 0.55→0.65→0.75 迭代链同源，重定切断纵向可比性；双向翻转机制下单次加跑
无法确立稳定值，正确工具是逐 case 归因纪律）。接受口径：thinking=disabled 下
L3 ∈ [0.75, 0.80] 为正常带，0.80 非新稳定值；**已知双向翻转清单扩展为
#7 / #11 / #16 / #19**（均 M4 已归档边界/风格类，方向可正可负）。观察项转 §7
待办：比较器 pass case 行尾中间注记（#7/#8/#17，展示层瑕疵）。

**条件与成本**：`llm.thinking: disabled`，其余与基线同（GLM-5.3-Flash、
eval temperature=0、runs_per_case=3、bm25+vector 双通道）；实跑 **5 分 24 秒**
（20 case × 3 轮 = 60 ask，均 ~5.4s；对照修复前同规模预计 ~50 分钟）。
`eval/baseline_e2e.json` 全程未动。
