### 裁定（选项 A，2026-09-20）

1. **冻结基线维持 0.75 不动**（禁止 `--save-baseline` 重定）。理由：0.75 锚点与
   0.55→0.65→0.75 迭代链同源，重定切断纵向可比性；双向翻转机制下单次加跑无法
   确立稳定值——正确工具是逐 case 归因纪律，不是更多采样。
2. **接受口径**：thinking=disabled 条件下 L3 ∈ [0.75, 0.80] 为正常带；本次 0.80
   不是新稳定值。**已知双向翻转清单扩展为 #7 / #11 / #16 / #19**（均为 M4 已
   归档的边界/风格类 case，方向可正可负）。
3. 观察项转 §7 待办：e2e 比较器在 pass case 行尾仍带出投影/单位等价判定前的
   中间注记（本次 #7/#8/#17）——展示层瑕疵，阶段二顺手修，不动判定逻辑。
