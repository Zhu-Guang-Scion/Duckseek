# 数据安全说明

DuckSeek 是本地优先的 CLI 工具：数据文件、查询结果与派生索引全部留在本机；唯一出网流量是调用你在环境变量中自行配置的 LLM / embedding 服务，除此之外无任何遥测或上报。

## 数据存放

- 原始 Excel（.xlsx/.xlsm/.xls）/ Access / Parquet 经 ingest 转换为 Parquet 落在本机 `data/`，以 DuckDB **只读视图**注册，不联网、不上传。
- `data/` 整体被 `.gitignore` 排除，仓库不收集任何用户数据；唯一例外是仓库自带的 NYC 出租车公开样本表（示例与评测用）。
- 画像、卡片、向量索引等派生物同样只落本机 `data/catalog/`。
- 溯源指纹（源文件 SHA-256 与表级行序无关 canonical 哈希，M8）只记入本地 `catalog.yaml`，用于"检出与登记内容一致"的证据链，不含任何数据行。
- 导出产物（M6：`result.xlsx` + `manifest.json`，含图表与 `input_digest`）全部落在本机 `data/exports/`，不自动清理、不上传。

## 出网内容（仅发往你配置的服务商）

- **embedding 服务**：schema 卡片文本（表名、列名、类型、统计摘要），用于建检索索引；维度表注入的值清单**不进入** embedding（M7 后检索通道已剥离，仅入提示词）。
- **LLM 服务**：你的问题、schema 卡片、词典条目，以及查询结果的压缩形式——超过 20 行只发统计画像与样本，不超过 20 行才内联发送。两点如实披露：
  - 小维度表（≤500 行）的全量值清单会随卡片进入 LLM 提示词（M7 实体值注入）——即该类**数据值本身会发往你所配置的 LLM 服务**，敏感维度值场景请评估或脱敏。
  - 多候选模式（`qa.candidate_count > 1`，M7）会把同一提示词发送 N 次（内容不变、次数增加），仅用于结果一致性投票。
- **原始明细数据文件永远不整表外发**，也不进入 LLM 上下文。
- 需要完全离线：把 LLM / EMB 端点指向内网或本地推理服务即可。

## 凭证

- API key 只从环境变量读取（`LLM_API_KEY` / `EMB_API_KEY`），不写入任何配置文件、日志、异常消息或工具返回值（有专项测试断言）；`.env` 凭证文件被 `.gitignore` 忽略，绝不入库。

## 查询安全

- LLM 生成的 SQL 必须通过 sqlglot 静态护栏九条规则：仅 SELECT / WITH、表白名单、表函数一票否决、列存在性校验、强制 LIMIT（封顶 10000）。
- 执行层只接受护栏签发的 `ValidatedSQL` 类型，DuckDB 以 `read_only=True` 打开，守护线程超时取消——绕过护栏的语句在类型层 / 数据库层即被拒绝。
- 累计 100+ 条红队对抗样本（提示注入、SQL 注入、文件读取、CTE 藏写）全部拦截，并固化为回归测试。

## 使用者注意

- 数据出网后的安全性取决于你选择的服务商：敏感数据场景请使用自有 / 内网端点，或先脱敏再入库。
- 答案附带的 SQL 可人工核验；导出产物（CSV / xlsx / manifest）的保存位置与后续去向由你自行控制。
- 多候选结果不一致时载荷会如实标注 `candidates_disagree`——此时答案未经多数确认，请核验 SQL 或复问。
