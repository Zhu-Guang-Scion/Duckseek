### 对 T21 的设计修正与确认

- **修正①温度**：原定「同温 0 靠固有非确定性」被证据否定——0.8-1.0 是被
  反复验证的区间（温度过低候选趋同，投票失效；CSC-SQL 扫描中 0.2 最差）。
  → **候选专属温度 `qa.candidate_temperature=0.8`**（仅 candidate_count>1
  生效；单发路径保持管线温度 0）。
- **确认②选择器**：执行结果多数决 = C3/DAIL-SQL 验证过的廉价基线
  （+0.4~1.3 EX）；更强选择器（LLM 裁判/微调分类器/CSC 式分歧修正）为
  后续升级路径——`candidates_disagree` 披露字段正是未来触发分歧修正的钩子。
- **参考③N 值**：API 场景证据区间 5-20；本仓库因个人成本取 3（多数决最小
  可行值），升到 5 是一行配置改动。
- **卫生步骤**（各家共有）：先滤执行报错 → 按结果去重分组 → 投票；同组
  保留首个成功者。

## 二、开源引擎横向（T21/T22 差异化定位）

核实对象：vanna（23.8k★，2026-03 已归档）、DB-GPT（20.1k★）、WrenAI
（17.8k★）、Chat2DB（28.3k★）、SuperSonic（5.1k★）、sqlchat、quary、
defog sqlcoder（停滞）、Dataherald（停滞）。

- **执行一致性投票：主流产品级引擎零实现**（全部「单次生成 + 失败修复」
  范式）；唯一公开先例在研究代码（CHESS/CHASE-SQL 系）→ **T21 是
  「研究有先例、工程上空白」的差异化特性**。
- **值链接**：SuperSonic 最完整（维值词典 + HanLP 分词 + 向量召回 + 值别名，
  Java 实现，`headless/chat/knowledge|mapper`）；WrenAI 把 Value profiling
  列为正确性支柱但完整形态仍在路线图；DB-GPT 仅 Excel 场景注入样本行；
  vanna 无预建值索引 → **T22 有直接对标（SuperSonic），「面向 SQL 候选的
  维表值注入 + 与投票联动」仍是差异组合**。

## 三、实体/值链接技术（T22 相关）

### 证据链

- **能塞下就全塞**：NeurIPS 2024「The Death of Schema Linking?」
  （[arXiv:2408.07702](https://arxiv.org/abs/2408.07702)）——现代大上下文
  LLM 在 schema+值能放进窗口时，**跳过检索、全量注入效果最好**（BIRD 71.83%）。
- **检索有噪声风险**：SIGMOD 2026 首个值链接对比研究——检索式值链接错误
  最多损 64% 执行准确率；小表全量注入完全规避该风险。
- **跨语言**：中文问句→英文库值的可靠通路是**双语值词典**（MultiSpider 2.0）；
  纯翻译路线（CSpider 基线）错误率高；LLM 隐式记忆不可靠（库值必须显式给出）。
- **注入格式**（CHESS/TREQS/MultiSpider 2.0 交集）：紧凑键值表 +
  护栏指令（WHERE 值必须来自词典；找不到时澄清而非猜值——DIVER 思想，
  与本项目诚实反问哲学同构）。

### 对 T22 的设计修正与确认

- **修正④token 上限**：原定 1200 过紧——265 行字典实测口径 2-3K token。
  → `cards.dim_value_token_cap=2000`，仓库 `retrieval.token_budget 2000→3000`。
- **确认⑤全量注入**：≤500 行维度表全量注入优于任何检索式方案（证据链如上）；
  CHESS 式 LSH 两段检索留作大表升级路径（数千行以上再启用）。
- **约束⑥中文别名列**：证据强烈建议双语词典，但 T5 契约「卡片纯机械装配
  禁 LLM」——自动翻译不可用；v1 以英文值全量注入 + glossary 词条承接跨语言
  （模型翻译能力 + 字典证据在场已可命中；「曼哈顿→Manhattan」类别名词条
  属人类数据，列入待办）。
- **护栏指令⑦**：注入段自带一行「过滤条件必须使用下列值原文；找不到时
  needs_clarification，不要臆造」——放在卡片内容层，不动人类审定的
  system.md。

## 四、结论

两项特性定位成立：T21 补工程空白（研究先例→产品化）、T22 对标 SuperSonic
但走「全量注入 + 与候选投票联动」的轻路线。设计修正四处（温度 0.8、注入
上限 2000、总预算 3000、护栏指令入卡片），全部有文献与源码双重依据。
