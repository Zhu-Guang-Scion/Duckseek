## 4. T15 三层判定 runner(2026-09-19)

交付:`eval/e2e.py`(三层判定 + 语义等价比对器 + 基线 diff)、CLI
`nl2data eval e2e [--golden] [--save-baseline]`、测试 13 项(比对器单元/
mock 三态/diff 报告/标签归一)。强制 --no-interpret(成本 ~20-60k tokens/
轮);单 case 异常按 error 计不中断;审计照常落盘。

**三层判定**:L1 召回(独立 retrieve,Recall@3);L2 SQL 层(ask_once 全链,
needs_clarification=fail、护栏拒/执行错=error,SQL 文本不比对);L3 结果层
(行数一致 + 行多重集合等价[列序无关;expected 含 ORDER BY 时行序敏感] +
数值容差 exact/float_rel_1e-4 + 车辆标签中英同义归一[依据 glossary 术语,
zone/borough 等真实语义差不归一])。

**敏感度 A/B 实证**(任务书验收核心):A=临时回退小费率词条至 T14 前表级
filter(模拟 #12 失败时代)→ 全量跑并存基线;B=恢复 T14 指标口径 → 重跑。
diff 输出:3 项指标变化(L2 0.85→0.90、L3 0.4118→0.6667 等)+ 5 条 case
转好——词条单点改动的影响被完整暴露。

**正式基线**(eval/baseline_e2e.json,git 跟踪;带标签归一后的 B 状态):
- L1 Recall@3 = **1.000**(20/20)
- L2 pass = **1.000**(20/20,全部执行成功)
- L3 pass = **0.55**(11/20;含可判口径 0.55)

L3 剩余 5 条真实语义差(回归改进的靶点,非 runner 缺陷):
- #14「每个区域」生成用 borough 级(8 行)vs golden zone 级(260 行)
- #18「有效」口径模型反问或实现与 golden 双过滤不完全一致
- #20「哪个区最高」应 LIMIT 1,模型返回全部分组(6 行)
- #17 存在轮间波动(非确定性采样),基线以本轮为准
- #3/#16 全 NULL 结果按 exact 判 pass(数据事实)

**"敢迭代"闭环达成**:改提示词/换模型/调参数 → `nl2data eval e2e` →
默认与基线 diff,指标与逐 case 变化即风险清单。

## 6. G8b 比对器语义化 + N=3 多数决 + 最终基线(2026-09-19)

**① 比对器放宽**:列超集投影(实际列多于期望且期望列名全部可对上时,
投影后比对)+ 数值单位等价(×100/÷100 命中时 pass 且 reason 带
unit_equivalent 标注,不静默);形状等价(行式/列式)明确不做。
**关键设计修正(任务书解读)**:字面"缺列仍 fail"在别名自由现实下全员误伤
(golden 用 vehicle/march_orders、模型用 cab_type/总订单量 等),首轮基线
崩至 0.40;改为**缺列时回退整体形状比对**——仅当列名可对上才投影,别名
措辞是合法变体而非语义缺口(新增回退测试)。#4(0.66 vs 65.99)经单位等价
转 pass 并带标注。

**② #11 口径注记**:golden note 逐字追加「对比类问题(哪个更高/更低)的
口径为输出双方数值的比较表;top-1 单行不构成完整答案」,SQL 维持双行。

**③ N=3 多数决**:eval 段 runs_per_case=3;每 case L3 跑 3 次,≥2 通过
判 pass,confidence 标注(如 1/3);温度 0 下残余非确定性被吸收。
成本:60 次问答/轮 ≈ 25-30 万 tokens(温度 0 + 无解读)。

**④ #14 残差定性**:expected 含 1 行 [None, 4723](locationid 未关联
zones 的 NULL zone 组);生成 SQL 将该组输出为数值标签——**非 zone 空串
↔NULL 混排**,按任务书如实上报、不归一化。

**最终基线**(N=3):L1=1.000 / L2=0.95 / **L3=0.75(15/20)**。
剩余 5 条归因:
- #10/#19(0/3):行式 vs 宽表形状差——①明确不做的设计边界,属风格类;
- #7(1/3):多列附加且列名对不上(回退后形状差),风格类;
- #14(0/3):NULL zone 组呈现差(④定性),风格类;
- #11(0/3 本轮 error):生成 SQL 把 tpep 用于 green 表(列名跨表混用),
  护栏正确拒绝——模型语义错误,非伪影;历史轮次曾 pass(摆动)。
风格类(#7/#10/#14/#19)已列 goals.md §7 提示词引导清单,不再动比对器。
